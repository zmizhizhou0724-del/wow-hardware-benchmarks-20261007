# 魔兽世界硬件实测

数据来源：哔哩哔哩视频创作者 51972《最好的魔兽世界硬件攻略》

https://www.bilibili.com/video/BV1P2Hf6aEJy/

该网页收录 469 行榜单、八个副本的 40 个跨平台测试单元、六套配置优化前后结果及 22 项设置。数据、样式与交互脚本均嵌入 `index.html`，下载该文件即可离线浏览。原视频证据链接需要网络。

网站保留原表硬件标注疑点与未公開的平台条件，不推断缺失硬件，不把补帧与原生帧数混排，不引入其他来源的跑分。原表跨平台汇总 97.4 与可见五格计算 97.2 的差异已注明。

所有资料仅用于展示原视频实测结果，版权与实测数据署名归原作者。网页不是实时价格或新版本游戏的性能保证。
